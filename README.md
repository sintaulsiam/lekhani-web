# Lekhani Web (লেখনী ওয়েবসাইট)

Official showcase and direct download hub for the [Lekhani (লেখনী)](https://github.com/sintaulsiam/lekhani) Bengali Input Method Suite for Android, Linux, and Windows.

---

## ⚡ Highlights

- **Live Browser Typing Sandbox**: Real-time phonetic transliteration & candidate strip emulator matching Avro phonetic rules and Bangla Academy standards.
- **Direct GitHub Releases**: One-click download links for verified APKs (`arm64-v8a`, `universal`, `armeabi-v7a`, `x86_64`) and automated Linux install scripts.
- **Tactile Keycaps & Audio Synthesizer**: Interactive on-screen mechanical keyboard with synthesized Web Audio switch clicks.
- **Searchable Phonetic Rules Cheatsheet**: Fast real-time lookup for vowels, consonants, kars, and complex conjuncts (*যুক্তবর্ণ*).
- **Hard Benchmarks**: Transparent performance telemetry comparisons (&lt; 100 &mu;s latency, 100% on-device zero telemetry).

---

## 🚀 Running Locally

To preview the website locally:

```bash
# Using npm
npm start

# Or using Python's built-in HTTP server
python3 -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
