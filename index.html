QUESTIONS & ANSWERS

Frequently Asked Questions

How does Lekhani differ from standard Avro Keyboard? ↓

Lekhani retains 100% muscle-memory compatibility with official Avro rules, but is rewritten completely from scratch in pure Rust. Unlike legacy tools, Lekhani incorporates an on-device contextual homophone ranker, verbal conjugation peeling (e.g. kortesi → করছি/করতেছি), and a sub-millisecond hardware canvas on Android.

Does Lekhani collect or transmit any typing data? ↓

Absolutely zero. The Android app does not even request the INTERNET permission in its manifest. The desktop Linux and Windows engines contain no analytics, no telemetry, and zero outbound network calls. Everything runs 100% locally.

Can I use Lekhani completely offline? ↓

Yes. The entire language model, Trie dictionary, phonetic grammars, and theme presets are packaged directly into the installation binaries. It operates completely independently of internet access.

How do I install Lekhani on Linux? ↓

On any Linux distribution with Fcitx5, run our official one-liner: curl -fsSL https://raw.githubusercontent.com/sintaulsiam/lekhani/main/install.sh | bash, or build directly with cargo install --git https://github.com/sintaulsiam/lekhani.
